# Ex02 Commercial Website

## Aim
To create a commercial website using CSS Flexbox.

## Algorithm

**Step 1:** Create the project files (`index.html`, `style.css`) and organize the required folders.

**Step 2:** Design the website with sections such as Navigation Bar, Home, Products, Offers, Customer Reviews, Contact, and Footer.

**Step 3:** Apply CSS styles using Flexbox, colors, fonts, images, and hover effects to create a responsive layout.

**Step 4:** Test the website in a browser and make necessary corrections to the design and functionality.

**Step 5:** Upload the project to GitHub and deploy it using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- Font Awesome
